# Awesome Lists
Awesome Lists are lists usually hosted on github that contain a bunch of links. Each can contain other sites/lists, information, or software.

### Legend
Blank: A site <br>
:star:: A great site <br>
:star2:: One of the best sites ever

## Lists
- :star: [Awesome Awesome Lists](https://github.com/sindresorhus/awesome) Awesome List of other Awesome Lists.
- :star: [Awesome Uncopyright](https://github.com/johnjago/awesome-uncopyright) Awesome List of media in the public domain. They typiclly have an [CC0 License](https://creativecommons.org/public-domain/#cc0), but sometimes even an [UNLICENSE](https://en.wikipedia.org/wiki/Unlicense).
