## Anything Upgrade Tree

Anything Upgrade Tree would be an upgrade tree game. I have felt inspired by the [Roblox](https://www.roblox.com) game [Everything Upgrade Tree](https://www.roblox.com/games/122809141833750/Everything-Upgrade-Tree). I really enjoyed playing through it as the incremental nature of the game can be addicting, but [Everything Upgrade Tree](https://www.roblox.com/games/122809141833750/Everything-Upgrade-Tree) added onto that by adding cool extra mechanics such as playing [Minesweeper](https://en.wikipedia.org/wiki/Minesweeper_(video_game)) to boost a currency. An upgrade tree game can host extensive expression and broader gameplay which would be good for a "Anything" type of game. I have not had any attempts at creating this.

Schizo-Clicker would be a cookie clicker game, but during gameplay you would encounter "Jumpscares". I had developed this during high-school with a friend utilizing [Scratch](https://scratch.mit.edu) it is called [Schizo Girlfriend](https://scratch.mit.edu/projects/776332348/). ## Guessle

I had participated in [FBLA](https://fbla.org) competetions for my entire high-school experince, so 4 years. I competed with my friend for the last two years and the rest were on my own. The events I did each year were Computer Game and Simulation Programming, Computer Game and Simulation Programming, Computer Game and Simulation Programming, and then Coding and Programming. My first year for Computer Game and Simulation Programming we were tasked to create a word game with the given example of [Wordle](https://www.nytimes.com/games/wordle/index.html), so I created a game called Guessle that was more of a level based [Wordle](https://www.nytimes.com/games/wordle/index.html) puzzles. Each level would have a catogory of possible words that were chosen randomly on beggining that level, to complete a level you would have to guess the word in 5 trys like [Wordle](https://www.nytimes.com/games/wordle/index.html). The thing I loved about it the most was the art as I put a lot of effort into drawing an alive alphabet in pixel art. That game is lost media now along with the following year's game, I only have my memories of them. The following year's game was a basic RPG around the given topic with nothing really notable. Both of those games did not place anything.

There is an very incomplete old apk exported version of the RPG which can be found [here](https://drive.google.com/drive/folders/1q2rkCxAMSh2UbaHjXxWhUBfGvB-WWpCU?usp=drive_link) called FBLA Quest.

## Finder-Blue 

Findr-Blue would be a solo recreation and updating to a program "Finder" that I developed with a friend for a competetive [FBLA](https://fbla.org) event. Finder was a business locater desktop application that utilized [OpenStreetMap](https://www.openstreetmap.org), [Electron](https://www.electronjs.org/), [Vue](https://vuejs.org), etc. You could have used it for just a google maps alternative too. Although I didn't put much effort into it, most of the work was done by my friend so I don't have the final product. We competed in [FBLA](https://fbla.org) 2026 representing Wisconsin Manitowoc Lincoln high-school in the Coding and Programming event. My friend and I got 1st place in Regionals and 2nd place in State. We competed in Nationals, but sadly did not get past the preliminary round. This is the same friend that I worked on [Schizo Girlfriend](#schizo-girlfriend-project) with.
